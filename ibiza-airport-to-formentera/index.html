Airport to port by road, then ferry to Formentera

Formentera has no commercial airport. This booking covers the private road transfer on Ibiza from Ibiza Airport to the confirmed ferry terminal or practical drop-off area at Ibiza Port. The scheduled ferry then operates separately to La Savina.

Important: the core road-transfer service described on this page ends at Ibiza Port. Ferry tickets and onward road transport on Formentera are separate unless they are expressly included in a written confirmation.

Connection planning

Allow a realistic margin between flight and ferry

Baggage collection, airport meeting, Ibiza traffic, port access and ferry check-in all require time. A delayed flight can make a tight ferry departure impractical, so an onward sailing should not be described as guaranteed.

Pricing covers the confirmed road transfer and any expressly agreed additions. The ferry ticket is not automatically included. If you need a return from Ibiza Port after arriving back from Formentera, send the ferry arrival and onward flight or hotel details separately.

Frequently asked questions

Ibiza Airport and Formentera ferry connection

Does Ibiza Private Drivers drive on Formentera as part of this booking?

No. This page describes the road transfer on Ibiza from Ibiza Airport to Ibiza Port. The ferry to La Savina and any onward transport on Formentera are separate unless expressly confirmed.

Is the ferry ticket included?

Not unless it is expressly included in a written confirmation. The road transfer, ferry ticket and onward transport are separate elements.

What details should I send for the ferry connection?

Send the flight number, scheduled arrival, passengers, luggage, ferry operator, ferry departure time and booking reference if available.

What happens if the flight is delayed?

The pickup can be coordinated using confirmed flight information, but an onward ferry connection cannot be guaranteed if the available connection margin becomes insufficient.

Can I book the return from Ibiza Port to Ibiza Airport?

Yes. Provide the ferry arrival information, requested pickup point, departure flight details, passengers and luggage so the return plan can be reviewed.
